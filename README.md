Procrastimates – Group Study Session Web App
Procrastimates

Procrastimates is a group study session web application that helps students stop procrastinating by studying together in real time. Users can create or join study sessions, connect online, and stay accountable by seeing who else is actively studying.


Tech used: React, Vite, JavaScript, HTML, CSS, Supabase

Procrastimates was built using React with Vite as the development and build tool to create a fast, modern front-end workflow. React allowed the UI to be broken into reusable components, while Vite provided instant hot reloading and a smooth development experience.
Procrastimates is a front-end focused project with an emphasis on clean UI, usability, and real-world behavior. We started by designing a simple layout that makes it immediately clear what how to create groups and set up meeting locations.
Supabase was used as the backend for handling data storage and real-time functionality. Integrating Supabase with the React frontend was one of the more challenging parts of the project, as it required managing asynchronous data fetching, syncing UI state with backend updates, and handling edge cases when data changed in real time.
JavaScript handles the core logic such as session timers, user interactions, and dynamic updates to the page. We focused heavily on structuring the code so that each responsibility was separated into clear, readable functions. CSS was used to keep the interface minimal and distraction-free, reinforcing the idea that this app is meant for focus.
Throughout the build, We iterated frequently—testing small pieces of functionality, refining the user experience, and improving readability as the project grew. The goal was to create something simple, functional, and easy to extend in the future.


This project reinforced how powerful well-structured JavaScript and React state management can be when building interactive applications. We gained a much stronger understanding of managing front-end application state, especially when multiple UI elements depend on the same underlying data.
Working with Supabase taught us valuable lessons about connecting a backend service to a frontend application, handling asynchronous operations, and debugging data flow issues between the client and server. Learning to incrementally build features and verify backend connections early made the overall development process much smoother.
Seeing Procrastimates go from an idea to a fully working study tool was a big confidence boost and motivated us to keep pushing our front-end and full-stack skills further.
